# ЗВЁЗДНЫЕ ВОЙНЫ: ПОСЛЕДНИЙ КРИСТАЛЛ

Многоступенчатый интерактивный квест с общим хранилищем на **Netlify Blobs**:
всё, что родитель меняет в `/admin` (тексты, подсказки, ответы, картинки,
видео, финальная подсказка, PIN), сохраняется на сервере и видно на любом
устройстве/браузере. Прогресс самого ребёнка (текущая миссия, XP, собранные
ключи) остаётся локальным на его устройстве — так и должно быть.

## Структура проекта

```
index.html                          — сайт (фронтенд, только структура заданий — БЕЗ ответов)
netlify.toml                        — конфигурация сборки
package.json                        — зависимость @netlify/blobs
netlify/functions/quest-config.mjs  — тексты/подсказки/медиа/PIN (общий конфиг)
netlify/functions/quest-check.mjs   — ПРОВЕРКА ОТВЕТОВ — единственное место, где хранятся правильные ответы
```

## Главный принцип безопасности

Правильные ответы **никогда не отправляются в браузер ребёнка**. Кнопка
«ПРОВЕРИТЬ» отправляет на сервер только сам ответ, а сервер (функция
`quest-check.mjs`) возвращает просто «верно/неверно» + количество XP.
Даже если открыть код страницы через «Просмотр кода», найти правильные
ответы там невозможно — они хранятся только в этой серверной функции и в
защищённом PIN-ом хранилище Netlify Blobs.

## Что реализовано полностью

- 10 основных миссий + необязательная секретная MISSION 11 (Дарт Вейдер),
  открывается, если пройти всё с не более чем двумя подсказками
- Многоступенчатые задания: STAR WARS знания → анализ → шифр/логика → код
- Связность миссий: каждая даёт «ключ», который виден в **VAULT**
  (хранилище) и используется в финальной миссии 10, которая требует собрать
  все девять ключей воедино
- Типы заданий: TEXT_INPUT, BINARY (двоичный код → ASCII), CIPHER (шифр
  Цезаря), ORDERING (расстановка точек маршрута тапом), MEMORY_TEST (20
  секунд на запоминание, затем ввод по памяти), QR_SCAN (сканирование камерой
  или ручной ввод ID, с настоящими маяками и имперскими ловушками ±XP)
- JEDI ARCHIVE — экран пройденных миссий (без ответов), с XP и количеством
  использованных подсказок по каждой
- XP по формуле из ТЗ: 100 / 75 / 50 в зависимости от использованных
  подсказок; QR: +50 за маяк, −50 за ловушку, без ухода в минус
- Загрузка картинок и видео к каждой миссии через `/admin`, хранится в
  Netlify Blobs, видно на всех устройствах
- Кинематографичный пролог с текстом из ТЗ, экран загрузки, финальный экран
  со статистикой

## Что упрощено (и почему)

ТЗ описывает очень широкий конструктор (18 типов заданий, полностью
визуальный редактор логических таблиц, drag-and-drop, произвольные
IMAGE_HOTSPOT-зоны на изображениях, безлимитные медиа-слоты на миссию).
Построить это как универсальный движок для *любого* контента, который
администратор придумает с нуля, — отдельный многомесячный проект. Вместо
этого сделаны **конкретные, полностью рабочие** реализации:

- **LOGIC_GRID** (миссии 2 и 9) → заменён на пошаговую текстовую логическую
  дедукцию (2 вопроса вместо визуальной таблицы 5×5×5×5×5)
- **DRAG_AND_DROP** (миссия 5) → реализован как тап-по-порядку (нажимаешь
  точки в нужном порядке), результат тот же, без библиотек drag-and-drop
- **IMAGE_HOTSPOT** → не реализован как поиск зон на фото; вместо этого в
  миссии 8 сделан честный MEMORY_TEST с таймером и сеткой цифр
- Один слот под изображение и один под видео на миссию (не «неограниченное
  количество медиа»), плюс аудио-эффекты интерфейса (звук ответа, ошибки,
  сканирования и т.д.) — но не выделенная аудио-дорожка на миссию
- Конструктор в `/admin` — текстовые поля (текст этапа, 2 подсказки, ответы,
  картинка/видео), а не визуальный drag-and-drop редактор логических таблиц

Все 10 миссий и секретная миссия **полностью играбельны и решаемы** —
головоломки проверены математически (шифр Цезаря, двоичный код, счёт букв).
Дефолтные ответы можно поменять под свой реальный сценарий через `/admin`.

## Деплой — только через GitHub или Netlify CLI

Как и раньше: перетаскивание файла (Netlify Drop) не подходит, так как нужна
установка npm-зависимости `@netlify/blobs` и сборка двух функций.

### Через GitHub (рекомендуется)

1. Создайте репозиторий на github.com
2. Загрузите все файлы из этой папки, сохранив структуру `netlify/functions/`
3. На app.netlify.com → **Add new site → Import an existing project** →
   выберите репозиторий → **Deploy**
4. Через 1–3 минуты сайт опубликован

### Через Netlify CLI

```bash
npm install -g netlify-cli
cd путь/до/папки
npm install
netlify login
netlify init
netlify deploy --prod
```

## После деплоя

1. Откройте `https://ваш-сайт.netlify.app/#admin`, войдите с PIN `1234`,
   сразу смените его
2. Впишите настоящий текст финальной подсказки
3. При необходимости замените дефолтные ответы под миссии 4 (тайник в
   квартире), 5 (реальный маршрут) и 6 (реальные QR-коды) — это единственные
   три миссии, которые обязательно зависят от вашей квартиры/города
4. Проверьте `/.netlify/functions/quest-config` в браузере — если видите
   JSON без секретных ответов, сервер настроен верно
